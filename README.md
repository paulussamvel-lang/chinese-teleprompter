# 中文口播提词器

一个可直接在浏览器打开的单文件提词器，适合录视频、练习口播和演讲。HTML、CSS 和 JavaScript 都在 [prompter.html](./prompter.html) 里，无需安装依赖或搭建服务器。

## 使用方法

1. 下载 [prompter.html](https://raw.githubusercontent.com/paulussamvel-lang/chinese-teleprompter/main/prompter.html)，用浏览器打开。
2. 点击「编辑文稿」，粘贴口播稿，再点「开始提词」。页面保留手动换行，长句优先在标点或词组边界断行。
3. 选择一种翻行方式：

   - **手动**：空格、右方向键或下方向键翻到下一行。左方向键或上方向键返回上一行。
   - **定时**：勾选「定时翻行」并填入秒数。默认 3 秒，支持 0.5–3600 秒及小数。手动翻行后重新计时。
   - **语音**：开启「语音」，按浏览器提示允许麦克风访问，朗读当前行即可跟读翻行。支持情况取决于浏览器，语音识别可能由浏览器的在线服务处理。

点击「停止」或按 Esc 结束。手动和定时模式可以离线使用。
